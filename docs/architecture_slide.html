🛡 Security & governance — enforced by architecture, not by prompt

1. Access controlpersona → Qdrant payload filter; customers cannot retrieve internal chunks; sign-in to act
2. Data sovereigntysensitivity per chunk; restricted evidence → on-device model; drafts inherit the rule
3. Groundingcitations mapped in code (no invented sources); version conflicts surfaced, newest wins
4. Human decisionagent prepares intake, coverage, recommendation; a specialist decides; all on the ticket history
📊 Audit & leak testevery model call, tool call, message & decision logged
0 restricted → cloud
